# Security Policy

## Reporting a Vulnerability

Submit all security vulnerability reports through the [Lido Bug Bounty program on Immunefi](https://immunefi.com/bug-bounty/lido). The Lido contributors do not review reports sent through other channels.

> [!IMPORTANT]
> Do not open a public issue or pull request on GitHub, and do not disclose the vulnerability publicly before the Lido contributors have addressed it.

## Scope

The [Immunefi program page](https://immunefi.com/bug-bounty/lido) defines the scope, rules, and rewards.

## Legal Inquiries

Send legal inquiries and formal notices to [legal-requests@lido.fi](mailto:legal-requests@lido.fi).
